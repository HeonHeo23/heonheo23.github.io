# 성공하는 사람들의 7가지 습관

## I. 개관

### 패러다임

내면으로 부터 시작하라. 원칙 중심의 패러다임. 새로운 차원으로의 사고를.

### 습관

Knowledge, skill, and desire.

**성숙의 연속선**:
의존적 단계 (상대방이 주체) --> 독립적 단계 (내가) --> 상호의존적 단계 (우리가)

효과성 = 생산 / 생산 능의

패러다임 - 행동 - 결과

## II. 개인의 승리

### 1. 자신의 삶을 주도하라 (개인 비전의 원칙)

주도성(proactivity): vs 결정론적 패러다임, 선택의 자유 & 책임감

적극적 행동, 주도적 말

관심의 원 / 영향력의 원: 직접적인 통제, 간접적인 통제, 통제 불가
--> 기대 (관심의 원), 결의 (영향력의 원) => 영향력의 원에 집중하라

결과와 실수

약속과 실행: 인식, 기량, 욕구 통제 --> 습관의 기초

### 2. 끝을 생각하며 시작하라 (개인 리더십의 원칙)

패러다임을 매사를 검토하는 기준과 표준

효과적이지 않게 바쁘게만? 모든 것은 두 번 창조된다 (LDS idea)

리더십: 방향, 나침반 vs 관리 (실체적)

자기 사명서

삶의 네 가지 요소 -> 원칙중심으로

1. Security 2. Guidance 3. Power 4. Wisdom

종합적 사고를 하라 (우뇌 개발)

### 3. 소중한 것을 먼저 하라 (개인 관리의 원칙)

독립의지: 결정하고 선택하며 나아가 여기에 일치되도록 행동하는 능력

효과적 관리는 소중한 것을 먼저 하는 것

'못 한다'라고 말하기 -> delegate (위임)
지시적 위임 vs 신임적 위임 (기대성과, 실행지침[제약], 가용자원,
책무확인, 손익 결과)

제 2사분면을 늘려라

#### 제 2사분면 도구

1. 일치성 -> 자기사명서, 역할, 장단기 목표
2. 균형 유지 ->
3. 사람 위주 -> 시간만을 다룰 때는 효율성, 이 때는 효과성
4. 융통성
5. 휴대 가능성

- 역할 규명 --> 목표 선택 --> 일정 계획 --> 매일의 적용 (스케줄, 위임)
